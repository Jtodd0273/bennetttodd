# Bennett and Todd Opticians 

A website for my mum's optician practice where patients can book appointments and staff can log in to review bookings, add and update patient records and approve email reminders

# Patients
-Home page with a slideshow, welcome text and opening hours
-About us and contact pages
-Online Booking, displays free times, enter details and choose to recieve email/sms reminders

# Staff
-Login Required
-Review new bookings and approve or cancel them
-Search, add and edit patient records
-Matches bookings with existing patients if name and contact details match
-Email reminders are queued when appointments are confirmed and sent when approved
-An audit log is kept of changes 

# Tech Stack
Framework : Next.js, React, Typescript
Styling : Tailwind CSS
Database and Authentication : Supabase
Email : Resend
Scheduled Jobs : Vercel cron
Hosting : Vercel (Not ready to go live yet)
